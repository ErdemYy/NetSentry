# ML Dataset Directory

This directory is reserved for raw and processed datasets (e.g., CIC-IDS2017).

## Policy
- Raw `.pcap` and `.csv` files are ignored by git (`.gitignore`).
- Download scripts and preprocessing pipelines must document exact source URLs, SHA-256 hashes, class distributions, and train/test split seeds.
